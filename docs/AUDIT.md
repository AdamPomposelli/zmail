## 2. Architecture livrée

```
dist/ZMail.app
 ├─ Contents/MacOS/ZMail              Swift/AppKit : fenêtre WKWebView, menus FR, badge Dock
 │    └─ pont natif HTTP 127.0.0.1 (jeton) :
 │         /ai/generate   Apple Foundation Models (on-device)
 │         /notify        UNUserNotificationCenter + action « Copier le code »
 │         /keychain      clé maîtresse AES-256 dans le Trousseau
 ├─ Contents/Resources/node           Node 22 embarqué
 ├─ Contents/Resources/engine/        @zmail/engine (un seul fichier)
 │    SQLite (node:sqlite + FTS5) · imapflow (IDLE) · nodemailer · mailparser
 │    pipeline IA · règles · détecteur d'habitudes · agent de désinscription · tRPC + SSE
 └─ Contents/Resources/ui/            @zmail/ui (React Router 7 SPA, Tailwind 4)
```

### 4 bis. Orchestration des modèles (seconde passe)

Retour de l'utilisateur : la fenêtre d'ajout de fournisseur demandait un modèle, et le défaut était `gpt-4.1-mini`. Corrigé en profondeur :

- **Architecture** : une connexion ne porte plus de modèle. Un orchestrateur route chaque capacité (tri, agent, désinscription) vers le modèle choisi par nos benchmarks, avec relais. La personnalisation par capacité est optionnelle (interrupteur « Personnaliser »).
- **Benchmarks réels** sur la clé ZenMux de l'utilisateur (14 modèles, 40 mails étiquetés dont 10 pièges, 8 commandes d'agent, prompts de production). Choix retenus : **Gemini 2.5 Flash Lite pour le tri** (96,7/100, 1,5 s, 0,105 $ / 1 000 mails), **DeepSeek V4.1 Flash pour l'agent** (100/100). L'ancien défaut `gpt-4.1-mini` obtenait 96,1/100 pour 0,370 $ / 1 000 mails, soit 3,5 fois plus cher.
- **Prévisionnel** : coût par capacité et comparatif des modèles, calculés sur le volume réel des comptes (simulable). Exemple à 150 mails/jour : ≈ 0,55 $/mois au total.

## 5. Limites et vérifications partielles

Honnêtement, ce qui n'a pas pu être prouvé de bout en bout sur cette machine :

1. **Apple Intelligence (F‑80, C‑05)** : *mise à jour* : depuis que Siri a été passé en anglais comme le Mac, macOS est passé de `usageRestricted` à `assetNotReady` : le modèle se télécharge, et ZMail l'affiche. Historique : macOS renvoyait `modelNotReady`. Cause trouvée dans les journaux système de ce Mac (M3 Pro, macOS 27.0.1) : `GMAvailability … usageRestricted, selectedLanguageDoesNotMatchSelectedSiriLanguage (system: en, siri: fr)`. La langue du Mac (anglais) diffère de celle de Siri (français), donc macOS bloque Apple Intelligence et n'a pas téléchargé le modèle : le catalogue de modèles est vide (`entries:0`). Les résumés de notifications de macOS sont indisponibles pour la même raison. À corriger dans Réglages Système → Apple Intelligence et Siri en alignant les deux langues, puis en laissant le Mac télécharger le modèle. ZMail l'utilisera alors en priorité, automatiquement ; une vraie génération n'a pas pu être testée d'ici là.
2. **Benchmarks** : 40 cas étiquetés couvrent les cas courants et des pièges, mais ce n'est pas un corpus massif. Les écarts de moins d'environ 1 point entre les modèles de tête ne sont pas significatifs. Le banc se relance en une commande quand de nouveaux modèles sortent.
3. **Vrais fournisseurs (F‑01)** : les tests tournent contre GreenMail (IMAP standard avec IDLE, MOVE, UIDPLUS). Les préréglages Gmail, mailbox.org, Namecheap, etc. reprennent les réglages publiés par ces services, mais n'ont pas été essayés avec de vrais identifiants. Gmail se connecte par **mot de passe d'application** ; l'OAuth Google n'est pas implémenté.
4. **Pièces jointes (F‑06)** : téléchargement (`/api/messages/:id/attachments/:n`) et images inline (`cid:`) implémentés, sans test automatisé (pas de pièce jointe dans les mails de démo).
5. **Fenêtre native** : vous avez refusé l'accès de capture à ZMail.app, et le shell n'a pas la permission d'enregistrement d'écran. Les captures viennent donc de la même UI servie par le moteur dans Chromium. L'app native a été vérifiée par ses journaux et ses API : moteur embarqué, pont connecté, IDLE ×5, notifications natives délivrées. Le déplacement de la fenêtre par les zones de titre (`data-drag-region`) est compilé mais n'a pas été essayé à la souris.
6. **Notifications et Trousseau** : l'app est signée ad hoc. macOS peut demander d'autoriser les notifications (Réglages Système → Notifications → ZMail), et le Trousseau peut redemander l'accès après chaque reconstruction.
7. **Hors périmètre du cahier des charges** : notes, modèles de mails, snooze, brouillons enregistrés côté serveur (le dossier Brouillons est synchronisé en lecture), voix, assistant SMS.
